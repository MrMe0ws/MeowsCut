# 00. Meows Cut — идея и границы продукта

## Суть

Настольный видеоредактор для Windows: **доска монтажа без тяжести большого NLE**.
Видео кладётся на таймлайн, режется ножницами, куски двигаются, ускоряются и настраиваются
покадрово — но без проектов на 40 дорожек, рендер-очередей и получаса на изучение интерфейса.

Формула: **источники → последовательность клипов на таймлайне → один экспорт.**

## Для кого

Автор проекта: есть базовый опыт монтажа. Знает, что такое FPS, битрейт, разрешение, кодек,
обрезка, субтитры. **Не нужно** объяснять азы и прятать всё за «умными» дефолтами.

Отсюда тон интерфейса:
- Термины называются своими именами: CRF — это CRF, а не «Качество ★★★☆».
- Дефолты разумные, но всё видно и всё меняется; ничего не решается за пользователем молча.
- Подсказки есть, но одной строкой и по делу («H.265 — вдвое меньше файл, хуже совместимость»),
  а не обучающими мастерами.
- Плотность параметров переключается: базовый набор ↔ расширенный (профиль, уровень, GOP,
  pix_fmt, два прохода, каналы аудио).

## Чем НЕ является

- Не Premiere / DaVinci: нет многослойного композитинга, эффектов с ключевыми кадрами,
  цветокоррекции по кривым, аудиомикшера с шинами.
- Не облако: **видео никуда не загружается**, вся обработка локальная.
- Не «редактор для бабушки»: упрощаем интерфейс, а не возможности.

## Принципы продукта

1. **Быстрый старт.** Бросил файл — уже можно резать. Никакого мастера создания проекта.
2. **Прямое манипулирование.** Резать, тянуть края, двигать клипы мышью на таймлайне.
3. **Честный предпросмотр итога.** Плеер играет собранную последовательность, а перед
   экспортом видно разрешение, FPS, кодек, битрейты и оценку размера.
4. **Undo для всего.** Любое действие на доске откатывается (`Ctrl+Z`).
5. **Ничего не ломаем.** Исходники read-only, недописанный результат на диске не остаётся.
6. **Любую операцию можно отменить.** Кнопка отмены реально убивает процесс и чистит мусор.
7. **Быстро там, где можно.** Не требует перекодирования — делаем remux/stream-copy.

## Границы версии 1.0

Входит:
- Открытие (диалог + drag & drop), информация о файле, миниатюры, несколько источников в проекте.
- **Таймлайн-доска:** одна видеодорожка со связанным аудио, клипы, ножницы (split),
  удаление с подтягиванием (ripple), перетаскивание, обрезка краёв, зум, снап.
- Плеер последовательности: воспроизведение сквозь клипы, скраббинг, покадровый шаг, I/O-маркеры.
- Свойства клипа: скорость (пресеты + custom), громкость, вкл/выкл звука.
- Экспорт: контейнеры MP4/WebM/MOV/MKV/AVI, кодеки H.264/H.265/VP9/AV1,
  разрешение, FPS, битрейт/CRF/целевой размер, аудио (кодек, битрейт, sample rate, каналы).
- Раздел Telegram Stickers с пресетами, вынесенными в конфигурацию.
- Прогресс, ETA, отмена, «Открыть файл» / «Открыть папку».

Сделано сверх первоначальных границ 1.0:
- Субтитры: вшивание SRT/ASS в кадр.
- Аппаратное кодирование NVENC / QSV / AMF с проверкой пробным кадром на старте.
- Отдельные аудиодорожки: музыка и озвучка живут своими кусками поверх видеоряда.
- Фотографии на доске, масштаб, поворот и смещение кадра (`ClipTransform`).
- Затемнение краёв клипа: появление из чёрного и уход в чёрное.
- Экспорт только выделенного куска и экспорт одной звуковой дорожки (MP3, M4A, WAV).
- Выравнивание громкости по EBU R128.
- Формат ролика 9:16, 1:1 и 4:5 с выбором «вписать или заполнить».
- Титры поверх кадра: своя полоса на доске, место, размер, цвет, плашка.
- Вырезание пауз по звуку.
- Черновик проекта `.meows` с автосохранением и восстановлением после падения,
  светлая и тёмная темы.

Сознательно НЕ входит (архитектурный задел заложен):
- Несколько видеодорожек, наложение, переходы, титры, эффекты, ключевые кадры.
- Поворот, стабилизация, цветокоррекция.
- Пакетная обработка нескольких файлов (очередь задач уже спроектирована под это).

## Ключевое техническое требование

FFmpeg — единственный движок обработки, и он **не протекает в UI**: ни один View не знает
про процессы, аргументы и stderr. Между ними — слой абстракций ядра.
