## Зафиксированные требования (ответы пользователя, 2026-09-09)

1. **Аудитория:** автор проекта, базовый опыт монтажа. Термины называть прямо, азы не объяснять.
2. **Интерфейс:** доска монтажа (таймлайн, ножницы, клипы) — сразу, без разделения на
   простой/PRO режим. Плотность параметров переключается (ADR-12).
3. **Язык:** русский, но строки сразу в ресурсах — английский добавляется позже без правки кода.
4. **FFmpeg:** кладём рядом с приложением; в разработке — `%LOCALAPPDATA%\MeowsCut\ffmpeg` (ADR-15).
5. **ОС:** минимум Windows 10 x64.
6. **Поставка:** portable-папка; установщик — возможно позже.

## Журнал

### 2026-09-09 (сессия 3) — этапы M0 и M1

**Сделано:**
- Решение из 5 проектов, `Directory.Build.props` (nullable как ошибка), `global.json` на SDK 8.0.425, `git init`.
- `Core`: модели `MediaInfo`/`VideoStreamInfo`/`AudioStreamInfo`, `Rational`, `FrameSize`, `TimeRange`,
  `MediaCapabilities`, `MediaFileTypes`; абстракции `IMediaProbe`, `IMediaToolsetLocator`,
  `IMediaToolsetProvider`; исключения с `ErrorCode`; `AppPaths`, `AppSettings`, `JsonAppSettingsStore`
  (атомарная запись, бэкап битого файла).
- `Ffmpeg`: `ProcessRunner` (только `ArgumentList`, UTF-8, асинхронное чтение обоих потоков,
  кольцевой буфер stderr, отмена «q → Kill(entireProcessTree)»), `FfmpegToolsetLocator` (6 источников),
  `EncoderProbe`, `FfprobeMediaProbe` + `MediaInfoMapper`.
- `App`: Generic Host + DI + Serilog (лог в UTF-8 с BOM), тёмная тема, окно с drag & drop,
  диалог открытия, карточки характеристик, недавние файлы, статус ffmpeg и выбор папки вручную,
  локализация через `Strings.resx` + `loc:Tr` (текста в XAML нет).
- `tools/get-ffmpeg.ps1`.

**Проверено:**
- 35 тестов зелёные; интеграционные создают клип настоящим ffmpeg и читают его ffprobe.
- Пути с пробелами и кириллицей работают (тесты специально используют «тестовый клип 1.mp4»).
- Приложение запущено: находит ffmpeg за ~0.3 с, лог читается без кракозябр.

**Известные упрощения (осознанные):**
- Отдельного окна онбординга при отсутствии ffmpeg нет — пока статус в строке и кнопка «Указать папку» (M9).
- Тестов на ViewModel нет: проект тестов для WPF-слоя появится на M4, когда там будет
  нетривиальная логика (метрики таймлайна, снап).
- Превью кадра не показывается — это M5 вместе с плеером.

**Следующий шаг:** M2 — `Sequence`/`Clip`/команды/`EditHistory` в Core с полным покрытием тестами.
